# App Store Marketing - Quick Start

This is your step-by-step checklist to create App Store screenshots and videos for Mob.

## What You Have

✅ **SCREENSHOT_GUIDE.md** - Detailed instructions for 8 screenshots  
✅ **VIDEO_GUIDE.md** - Scripts for 3 demo videos (15-30 seconds each)  
✅ **TEST_DATA.md** - Sample conversations, files, and content to populate the app  
✅ This checklist

## Timeline

**Total time needed:** 2-4 hours
- Setup and test data: 30 minutes
- Screenshots: 1 hour  
- Videos: 1-2 hours
- Editing and upload: 30 minutes

## Step-by-Step Process

### Phase 1: Preparation (30 minutes)

1. **Read the guides**
   - [ ] Skim SCREENSHOT_GUIDE.md to understand what you need
   - [ ] Skim VIDEO_GUIDE.md to see the video flow
   - [ ] Review TEST_DATA.md for content examples

2. **Prepare your iPhone**
   - [ ] Charge to 100% or connect to power
   - [ ] Set time to 9:41 AM (Settings → General → Date & Time → Set Manually)
   - [ ] Enable Do Not Disturb (Control Center)
   - [ ] Clear all notifications
   - [ ] Close background apps
   - [ ] Add Screen Recording to Control Center (if recording videos)

3. **Prepare your office Mac (mobd running)**
   - [ ] Clean desktop - remove personal files
   - [ ] Open VS Code or Xcode with a clean project
   - [ ] Set professional wallpaper
   - [ ] Hide sensitive info from dock/menubar
   - [ ] Ensure mobd is running and accessible

4. **Prepare the app**
   - [ ] Fresh install or clear old test data
   - [ ] Pair with your office Mac
   - [ ] Create conversations using TEST_DATA.md examples
   - [ ] Add test files (or prepare to upload them)
   - [ ] Configure 2-3 machines in Settings
   - [ ] Set up agent handles (@api, @backend, etc.)

### Phase 2: Screenshots (1 hour)

**Device:** Use your iPhone 14 Pro Max or 15 Pro Max

5. **Take screenshots in order** (SCREENSHOT_GUIDE.md for details)
   - [ ] Screenshot 1: Hero - Chat with AI Agent
   - [ ] Screenshot 2: Live Desktop View
   - [ ] Screenshot 3: Agent Collaboration
   - [ ] Screenshot 4: File Transfers
   - [ ] Screenshot 5: USB Device Sharing
   - [ ] Screenshot 6: Multiple Machines
   - [ ] Screenshot 7: Request Details & Cancel
   - [ ] Screenshot 8: Conversation List

6. **Review screenshots**
   - [ ] All text is readable
   - [ ] No personal information visible
   - [ ] Professional appearance
   - [ ] Proper framing (nothing cut off)
   - [ ] Good quality (not blurry)

7. **Export screenshots**
   - [ ] Transfer to Mac via AirDrop or USB
   - [ ] Save to Marketing/Screenshots/ folder
   - [ ] Name: 01-hero-chat.png, 02-live-desktop.png, etc.
   - [ ] Keep originals in Photos app as backup

### Phase 3: Videos (1-2 hours)

**Optional but recommended** - Videos significantly increase App Store conversion

8. **Record Video 1: "Mob Your Work"** (25 seconds)
   - [ ] Practice the flow 2-3 times
   - [ ] Start screen recording
   - [ ] Follow script in VIDEO_GUIDE.md
   - [ ] Stop recording
   - [ ] Review - re-record if needed

9. **Record Video 2: "Collaborate"** (20 seconds)
   - [ ] Practice the flow
   - [ ] Record following script
   - [ ] Review and re-record if needed

10. **Record Video 3: "Access Everything"** (28 seconds)
    - [ ] Practice the flow
    - [ ] Record following script
    - [ ] Review and re-record if needed

11. **Edit videos** (optional but recommended)
    - [ ] Trim to exact length (15-30s each)
    - [ ] Add text overlays (suggested in VIDEO_GUIDE.md)
    - [ ] Export as MP4 (H.264, 1080×1920)
    - [ ] Save to Marketing/Videos/ folder

### Phase 4: Upload to App Store Connect (30 minutes)

12. **Navigate to App Store Connect**
    - [ ] Go to appstoreconnect.apple.com
    - [ ] My Apps → Mob
    - [ ] Select your version (or create new version)
    - [ ] App Store → App Previews and Screenshots

13. **Upload screenshots**
    - [ ] Select iPhone 6.7" display size
    - [ ] Upload all 8 screenshots in order
    - [ ] First screenshot is most important (hero shot)
    - [ ] Wait for processing

14. **Upload videos** (if created)
    - [ ] Same section as screenshots
    - [ ] Upload up to 3 videos
    - [ ] Wait for processing (may take 5-10 minutes)
    - [ ] Set poster frame (thumbnail) for each video
    - [ ] Choose compelling moment, usually 2-3s in

15. **Update text content** (while waiting for processing)
    - [ ] Update app description (see TEST_DATA.md for suggestions)
    - [ ] Add/update keywords
    - [ ] Update promotional text
    - [ ] Update what's new (if releasing new version)

16. **Review and save**
    - [ ] Preview how it looks in App Store
    - [ ] Check all screenshots loaded correctly
    - [ ] Check videos play properly
    - [ ] Save changes

### Phase 5: Additional Localizations (Optional)

If you want to add Chinese or other languages later:

17. **Translate content**
    - [ ] Get descriptions translated
    - [ ] Optionally create localized screenshots
    - [ ] Or just use English screenshots with translated text

18. **Upload for each locale**
    - [ ] Select language in App Store Connect
    - [ ] Upload localized screenshots (or reuse English)
    - [ ] Add translated text

## Tips for Success

**Screenshots:**
- Take multiple shots of each scene - pick the best
- Use actual functionality, not mockups
- Keep it clean and professional
- Text should be readable but not too dense

**Videos:**
- Practice makes perfect - run through 3-5 times before recording
- Smooth, deliberate gestures - no fumbling
- Keep it snappy - every second counts
- Show real functionality, not staged perfection

**General:**
- Start with screenshots (easier, required)
- Videos are optional but worth the extra effort
- Get feedback from a friend before uploading
- You can always update screenshots later

## What If I Get Stuck?

**Problem:** Can't get good test data in the app  
**Solution:** Create 2-3 real conversations with your actual office setup, then clean up the content for screenshots

**Problem:** Videos are too hard/time consuming  
**Solution:** Skip them for now - screenshots alone are fine. Add videos in a future update.

**Problem:** Screenshots don't look professional  
**Solution:** Try the Xcode simulator method (mentioned in guides) for more control, or hire a freelancer on Fiverr ($50-100)

**Problem:** Office Mac desktop looks messy in live view  
**Solution:** Create a clean test project just for the demo, or use simulator recording instead
